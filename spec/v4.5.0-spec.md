# v4.5.0「性别与远方」技术规格

## 背景与依据

* 用户要求：①加性别系统，人和动物都要（不能只是标签，要参与机制）；②离镇的人不能"出去了就没了"——计划书第二章「无限世界」早已定下："远处不是没有，是降精度"，要能看见走出小镇的人去了哪。

* 计划书第三章·身体："性：欲望、冲动、羞耻、压抑；生育：怀孕的辛苦、生产的危险、难产"。第二章·视野："没有限制，想拖到哪就看到哪"（现 boot.js clampCam 把相机钳在 -4..76，违背此条）。

* 零硬编码铁律：只写物理/概率机制，方位词/状态词由坐标与角度推导。

## 现状关键事实（已勘察）

* NPC.sex 仅作标签：pairCheck 异性过滤、tryBirth 女性 18-44 瞬时直生（无怀孕过程）。

* 动物（animals.js）无 sex/年龄/繁殖；野生种群靠 spawnWild 每日凭空刷。

* finalizeDepart（game.js 780-799）把离镇者 push 进 this.left 即从模拟删除；UI 只留一行历史记录。

* 地图已无限（chunk.js）；settlement.js 已有多聚落骨架（initSettlements 起源+1 个空聚落，interactSettlements 有移民机制）。

* 存档：npcs 内联序列化（game.js 241-255），animals 整对象直存，settlements 有 serialize/hydrate。

* selftest.js：tryBirth 在 1458 行以注入 rng 测直生（需改）；forceBirth（game.js 801）被 selftest/smoke 依赖，须保持"同步得子"语义。

## 设计

### A. 性别系统（人）

1. **取向字段**：NPC 构造器加 `this.orient`——`mulberry32(hashStr(def.id+'|orient'))` 决定，\~90% 'hetero' / \~10% 'homo'（确定性与 attachCrush 同法）。secret.js 新增导出 `attractedTo(n, sex)`：hetero→异性，homo→同性。attachCrush 候选过滤改用 attractedTo（替换硬编码 `o.sex !== n.sex`）。pairCheck 加双向取向兼容过滤（婚姻在此模拟中是生育制度，故仍需男女组合：两人 attractedTo 对方 sex 且 sex 不同）。
2. **欲望（needs.desire）**：构造器默认 15。`desireDaily(game, day)`（life.js 新增，onNewDay 调用）：16+ 成人日增 2-5（46+ 减半）；已婚夫妻 60%/夜纾解（双方 desire 减 40-70、mood+2、bond+1）；未婚 desire>75 → mood-2/日（压抑）。
3. **求偶加权**：pickChatTarget 权重加吸引项——成年单身 && 对方成年 && attractedTo → `+ needs.desire * 0.04`（上限+4，不破坏 v4.4.2 已验证的社交平衡）。
4. **怀孕过程**（替换瞬时生育）：

   * `conceptionDaily(game, day)`：已婚、女 18-44、未孕、夫在镇 → p = 0.015 + 双方均欲/100×0.035（约婚后 20-60 天受孕）→ `m.preg = { day0, due: day0+280, fatherId }`。

   * `pregDaily(game, day)`：energy 额外 -2、mood ±3 摆动；里程碑（30 有喜/150 显怀/260 临盆）写记忆+亲属感知；孕晚（due-当日<45）走速 ×0.85（npc.js tick 550 行速度式乘因子）。

   * `birthDaily(game, day)`：到期分娩——正常：makeChildDef+addBorn；凶险：夭折 2%（log+父母记忆）；难产 8% → injure 母亲，若母亲最差部位 cond<40 再 25% → startDying('产后血崩')。makeChildDef 补 father 为 null 的守卫（父已亡/离镇时用母亲外貌）。

   * `tryBirth` 改为受孕判定（保持导出名，返回孕事或 null）；game.js onNewDay 879-880 的直生调用改为依次调 desireDaily→conceptionDaily→pregDaily→birthDaily。

   * `forceBirth`（调试锤，selftest/smoke 依赖）：不再走 tryBirth，直接 makeChildDef+addBorn 同步得子，签名与语义不变。

### B. 性别系统（动物）

1. ANIMAL\_DEFS 每种加 `maturity`（成熟天数）、`gest`（妊娠天数）、`litter:[min,max]`、野生 `wildCap`（wolf6/deer10/bird14）：chicken 15/18/\[2,4]、sheep 25/30/\[1,2]、cow 40/60/\[1,1]、dog 20/22/\[1,3]、cat 18/22/\[1,3]、wolf 30/32/\[1,2]、deer 35/40/\[1,1]、bird 10/12/\[1,2]。
2. makeAnimal 加 `sex`（默认 50/50 公/母）、`ageDays`（默认=maturity 即成年）、`preg:null`。
3. animalDailyTick 增繁殖段：ageDays++；未孕成年母 10 格内有成年公同类 → 概率受孕（野生 10%/驯化 8%/伴侣 6%；game.animals.length>60 或该野生种达 wildCap 跳过）；孕期递减→产仔（litter 随机，ownerId 继承，落母旁；幼崽 ageDays=0、不产出、不入捕食成体判定外的特例）；驯化产仔 log（'母羊下了崽'类由 def.name+sex 推导）。
4. tickAnimals 行为：成年公决策时 12 格内有可配母 → 目标偏向母（求偶）；孕母游荡半径收缩守家。
5. 旧档兼容：hydrate 动物时惰性补 sex/ageDays（`mulberry32(hashStr(a.id))`）。

### C. 离镇者·无限世界（wanderer.js 新模块）

1. **实体不毁**：finalizeDepart 尾部改为调 `finalizeToWanderer(game, n)`——n 从 npcs 移入 `game.wanderers`（完整 NPC 对象，记忆/关系/身体全保留），`n.wand = { bearing, state:'trail', tx, ty, sinceDay, daysOut:0, settId:null, status }`。bearing = 镇中心→镇口方向 ±0.6 弧度抖动；this.left 历史记录保留（按 id 去重）。
2. **降精度日模拟**（第二章·二"远处逐天"）`wandererDaily(game, day)`：

   * 行进：trail 态沿 bearing 走 25-45 格/天，候选 6 次拒采样避水（chunk ensure 后查 ground），ensure 目的地 chunk（走到哪哪展开）。

   * 生存：hunger 日增 8-14；目的地 5×5 内有树/草地 → 65% 觅食 hunger-18；hunger≥100 → 8%/日饿死。

   * 事件（概率）：发现 45 格内聚落 55% 投奔→8 格内落脚（state=settled，settId）；trail≥4 天且离镇>55 格且近树临水 5%/日自立新营（makeSettlement+founderId，log+chronNote+markNote）；狼袭 1.2%/日（70% 受伤减速/12% 客死）；风雪 1%/日（trail 且 stormy/snowing）客死；消息传回 4%/日（镇民记忆+log"有行脚人捎话"）；思乡（mood<30 或镇上有家人加权）→ state=return 走向镇口，距镇中心<10 → visitStart。

   * 客死：就地 ensure chunk 立坟（setObj GRAVE+markNote），入 game.dead（cause 含情形），噩耗传回（亲属记忆+mood，log）。
3. **帧连续**（看得见）：`wandererFrame(game, dtReal)` 挂 game.loop（tickAnimals 后）——向 tx,ty 直线走（动物式 1.2 格/现实秒，避水滑动），到了就 ±2 闲荡；settled 态绕聚落中心 ±3。
4. **回乡探亲**：visitStart——移回 npcs，置 `n.visiting={untilDay:day+1}`，落镇口，全镇感知（家人 mood+4）；pushScore 跳过 visiting；到期 visitEnd——移回 wanderers（state=trail 重新上路，log"又上路了"）。
5. **聚落人口口径**：tickSettlement 人口加数 game.wanderers 中 settled 于该聚落者（对无 wanderers 的 mock 做守卫）。

### D. 呈现

1. render.js：动物层后增离镇者层——`drawNpcBody(T, ctx, wn, labels)`（名字标签常驻，野外可辨认）；有人（含落脚离镇者）的非起源聚落中心画小营帐标记（纯 canvas 三角，无新素材）。
2. ui.js「离镇的人」面板 → 实时版：每位离镇者一行——名字 + 状态（方位 8 向由坐标角推导 + 距镇格数 + trail/settled/客死），点击行相机跳到其位置（game.renderer.cam 按 boot.js 同款视口公式）；历史上无实体的 left 记录仍列于后。Inspector 需求条加「欲望」；有孕显示状态行（有孕·X 日）。
3. boot.js：clampCam 去边界（第二章·四视野无限制；drag 本就不钳，keys/小地图点击拉齐）；小地图维持镇区局部视图不动。

### E. 存档

* npcs 序列化加 `orient/preg/needs.desire/visiting`；hydrate 惰性补默认值（旧档 orient 按 id 哈希定、desire=15、preg=null）。

* `game.wanderers` 序列化：与 npcs 同一映射（抽模块级 `_serNpc/_hydNpc` 辅助，npcs/wanderers 共用；wanderer 不绑房）；hydrate 时对 wanderer 子代精灵 registerChild（镜像 410-411 行现有逻辑）。

* 动物新字段随整对象直存自动随档，hydrate 补缺。

## 明确不做

* 不做同性婚姻（取向只影响吸引/暗恋/求偶加权）。

* 不做"生了不想要的"等内容向叙事。

* 不重建无限小地图；不给野生动物加点击 Inspector。

* 离镇者不参与镇内 chunk 温度系统（荒野无需生长 tick，省性能）。
