# 序

你打开游戏，看到的不是一个等待你操作的小镇，而是一个正在自己活着的地方。

没有人等你。没有人需要你。你不在的时候，他们出生、长大、相爱、争吵、建造、离开、死去。你回来的时候，世界已经往前走了很远。

你是唯一能看到全局的存在。但你看不到任何人的内心。

你可以下一场雨，但不知道会淋到谁。你可以埋一条矿脉，但不知道谁会去挖。你可以给一个人托梦，但他怎么理解你的话，是他的事。

你唯一确定的，是这个世界不需要你。

# 第一章 世界的底色 【已交付·设计已定】

## 一、框架与状态

世界分两层。

**框架层**：物理常数、守恒、因果、时间、空间、代价、有限。写死在引擎里，任何存在都不能违反。永远不会因居民而改变。

**状态层**：地形、气候、生态、资源分布。可以被居民的行为慢慢推动，但只能通过时间累积。

**居民只是这个世界里发生的事。** 文明繁荣，地球不因此变好。文明灭亡，地球不因此变坏。世界不给意义，意义是人自己给的。

## 二、六条永恒定理

| 定理 | 含义          |
| :- | :---------- |
| 守恒 | 物质不凭空生灭     |
| 因果 | 有因才有果，且不可逆  |
| 时间 | 单向，不可倒流     |
| 空间 | 连续，不可跳跃     |
| 代价 | 任何改变都有成本    |
| 有限 | 资源、寿命、精力都有限 |

**六条永远不变。变的是定理的显现。**

## 三、窄而深的框架

**窄**：只管六条定理，不规定任何结果。
**深**：表达力足够容纳任何不违反定理的东西。

表达力必须支持：物体有属性、物体可组合、组合产生新属性、属性影响行为。

**定理是禁止，表达力是允许。两个都要有，世界才能一直长。**

## 四、没有保底

这个世界不是乌托邦。文明可能崩，可能死透。技术可能发明出让人活不下去的东西。灾难可能压垮整个社会。

**没有"文明总会找到出路"的暗设，没有救世主。**

世界可以死，也可以从废墟里重生。世界的伤疤，就是它的新样子。

# 第二章 无限世界

## 一、地图

- 无限延伸，按需生成
- 区块 64×64 tile
- 坐标 + 世界种子，确定性哈希

【已交付 v2.1.0】chunk.js：64×64 区块按需生成，坐标+世界种子确定性哈希；WorkingSet 管理已生成区块，serializeChunks 随档走。起源 2×2 区块（128×128），城镇 72×72。

## 二、四层模拟精度

```
活跃区（视野内 + 附近） → 逐帧
邻近区（几屏外）        → 逐小时
远处区（已知但远）      → 逐天
未知区（未访问）        → 不模拟，按需生成
```

**远处不是"没有"，是"降精度"。**

【部分】区块温度状态机已落地（v2.1.0，v2.3.0 接线）：VIRGIN 未生成不模拟 → COLD 冷 → COOL 逐日生长 → WARM/HOT 逐时 tick；NPC 脚下 HOT、四邻 WARM，闲置逐时冷却。简化版分层，未到逐帧/逐时/逐天全四级。

## 三、世界的冷与热

- 默认是冷的：有地形、有资源，但没有事件、没有历史、没有故事
- NPC 走到哪，哪就热起来
- NPC 走了，区块降精度
- 玩家视野自由移动，看不到没被 NPC 点燃过的地方

**远方不是预设的，是被走出来的。世界的历史不是写在文本里的，是刻在地形里的。**

【部分】NPC 走到哪哪热（promoteToHot/WARM）与走后冷却已交付（v2.1.0 接线 v2.3.0）；考古痕迹刻地形已交付（v2.0.0 markNote）。"玩家看不到没被点燃过的地方"未做。

## 四、视野

**没有限制。你想拖到哪就看到哪。**

真正的边界是"那里还没被生成"，不是"你看不见"。远方的荒野本来就不存在，NPC 走过去它才展开。这不是限制，是世界本来的样子。

【未做·设计已定】

# 第三章 居民

这是整个项目的命门。

## 一、目标标准

> 玩家永远猜不到他会做什么，但事后永远能理解他为什么这么做。

只有前半句 → 随机，是噪音。只有后半句 → 可预测，是机器。同时满足，才是活人。

【设计已定】

## 二、独特性来自数据，不来自模型

同样一件事，进入不同的人，变成不同的记忆，产生不同的行为，引发不同的事件。**这就是分叉。分叉累加几十年，就是真实。**

【设计已定】

## 三、身体是地基 【已交付 v1.3.0】

```
身体 → 感知 → 认知 → 社会 → 历史
```

- 病痛：慢性的、突发的、拖着不好的、疼一辈子的
- 残障：天生的、工伤断手的、瞎了一只眼的、瘸腿的
- 衰老：手抖、耳背、看不清、记忆流失
- 饥渴冷热：不是数值，是感受
- 性：欲望、冲动、羞耻、压抑
- 生育：怀孕的辛苦、生产的危险、难产、生了不想要的

**一个瘸腿的铁匠，和健全的铁匠，是两种人生。**

身体必须**部位化**：头/颈/躯干/双臂/双腿，每部位有当前状态、旧伤、劳损。状态本身就是行为约束——腿伤的老人会绕开坡，手抖的铁匠打出来的东西精度低。

**v1.3.0 实现**：`body.js` —— 七部位 cond/wear/scar、职业劳损映射、旧伤留疤、慢性病、60 岁起衰老、冷热是感受、腿伤步慢/手伤手工差/体质上限限精力。

## 四、七层档案 【部分】

| 层   | 内容                       | 变化速度    | 状态           |
| :-- | :----------------------- | :------ | :----------- |
| 体质层 | 代谢、睡眠、体力上限、痛觉、免疫、寿命、残障   | 终身，缓慢衰退 | 【已交付 v1.3.0】 |
| 气质层 | 反应强度、情绪基线、风险偏好、新奇追求、社交能量 | 终身基本不变  | 【未做】         |
| 品格层 | 价值观、道德边界、底线、执念、恐惧        | 年为单位    | 【未做】         |
| 能力层 | 技能等级、技能自信                | 月为单位    | 【未做】         |
| 信念层 | 对世界的看法，其中一部分是错的          | 月到年     | 【未做】         |
| 习惯层 | 口头禅、小动作、固定路线、仪式          | 基本不变    | 【未做】         |
| 状态层 | 需求、情绪、当前意图               | 分钟到小时   | 【已交付】        |

**技能自信不等于技能水平。** 实际 3 自信 9 的人会接他做不了的活，然后搞砸或者奇迹般学会。这个差值本身就是故事引擎。

**信念可以是错的。** 他相信"东边的林子有鬼"，所以一辈子不往东走。错误信念比正确信念更能产生行为。

## 五、默认状态是活着 【已交付 v1.3.0】

NPC 的空闲状态不该是"待命"，是**存在本身**。发呆、抖腿、看天、打瞌睡、想心事、什么都不想。

**做事是从存在里中断出来的，不是常态。**

**如果每个 NPC 每时每刻都在有意义地活着，那不是生活，是戏剧。**

**v1.3.0 实现**：`pickExistence` 八种存在态（发呆/看天/想心事/什么都不想/踢石子/抖腿/哼小调/打瞌睡），55% 存在概率。

【已交付 v1.4.1】存在态已可视化：打瞌睡冒 z、哼小调音符、想心事三点、踢石子、抖腿颤动、看天仰头（第十二章·八）。【已交付 v1.5.0】可视化与名牌随身量锚点（headTop），婴儿/儿童 0.75、少年 0.88 身量——存在态在孩子身上也看得见。

## 六、关系是独立对象 【已交付 v1.6.0】

每段关系有自己的历史：亲密度/信任度/亏欠/怨恨/恐惧/依赖六个独立维度，标签（可互相矛盾），共同记忆，未说出口的话，最后一次互动，误解。

**最重要的是误解。** A 以为和 B 是好朋友，B 觉得只是认识。这个不对称永远不会自动对齐。

**每段关系是单向存储的。** A 对 B 的关系，和 B 对 A 的关系，是两个独立对象。

【已交付 v1.6.0】social.js：makeRelation 六维关系对象（close/trust/owe/grudge/fear/depend），bond 六维聚合计分（0.6/0.4/0.12/0.15/-0.55/-0.25）写回 relations 供婚配/葬礼/快照等旧链路使用；每段关系单向存储在各自的 rels 里；标签由六维刷新、可互相矛盾（知心与忌惮长在同一人身上）；共同记忆同一天各存各的版本；未说出口的话；误解 meta 是单方面的自我叙述，**永不自动对齐**；ensureRels 旧档惰性升级。【已交付 v1.5.0】婚配最小闭环：pairCheck 好感门槛配对互设 spouse。

## 七、记忆会失真 【部分·失真物理已落地 v2.4.0】

| 类型   | 说明           |
| :--- | :----------- |
| 事实记忆 | 发生了什么        |
| 情感记忆 | 当时的感受        |
| 重构记忆 | 后来被自己改写过的版本  |
| 压抑记忆 | 不愿意想起的       |
| 虚假记忆 | 他坚信发生过，但没发生过 |

**每次回忆，都会被当前情绪重新染色。** 同一个记忆，不同时候读出来，内容不一样。

实现：记忆存原始版本，每次被检索时按当前情绪重写，存为新版本。**记忆自己会漂移。**

**成本警告**：字面实现 = 每次回忆一次 LLM 调用。必须缓存 + 限频 + 只在情绪明显变化时重写，否则是财务灾难。

【部分】现状：环形记忆 40 条；`orig` 永不改、`recall` 按当前情绪染色、drift>10 重构（旧真相永失）已落地；v2.4.0 接线：`tintRecall` 纯函数染色进 gossip 复述（传话的人什么心情，话就走什么味）、聊天话题 30% 取染色记忆（错信息驱动行为）、`oralOf` 口述与考古真相永不对齐（不设 reconciler）。虚假记忆/压抑记忆的 UI 呈现未做。

## 八、秘密与表演 【已交付 v1.4.2】

【已交付 v1.4.2】secret.js：秘密四状态映射（knownBy 空=藏着 / selfDeceived=自欺 / 1=不知人知 / 2=不知人知其知）、probeSecret 探话、tellLie 撒谎（pressure→leakRisk）、slipHint 话里带话、leakTo 定向泄漏、gossip 闲话；装病（mood<30 触发，真话只进私密自白）；自欺者嘴硬不记账、泄漏无自觉、crushGaze 路过慢行。

**秘密的四个状态**：他藏起来不让别人知道 / 不让自己知道（自我欺骗） / 不知道别人知道 / 不知道别人知道他知道。

**表演是主动操纵**：撒谎、装病、装可怜、当面一套背后一套、社交面具。

**人每天大部分社交，都是在演。**

**自我欺骗最有意思。** 他嘴上说"我不在乎她"，但他每次路过她家都放慢脚步。这个矛盾不该被修正，就该让它存在。

## 九、矛盾 【已交付 v1.4.2】

【已交付 v1.4.2】secret.js：makeMind 每人 1-3 个矛盾（leave/please/guilt/novelty/confess/duty 六模板），lean 每日摆动钳 0.15..0.85 永不收敛；lean>0.62 外出 / <0.38 宅家行为分化；dominantConflict 主导矛盾进快照（秘密与私密自白永不进快照）。

每个 NPC 有一到三个核心矛盾，永久存在：想离开小镇但放不下母亲、想被所有人喜欢但不愿意说违心话、相信自己是个好人但做过一件坏事。

**矛盾不解决。** 它只是在不同的时刻，让不同的那一面占上风。**连他自己都不确定明天会选哪边。**

## 十、生命周期 【已交付 v1.5.0】

```
出生 → 婴儿 → 儿童 → 少年 → 成年 → 老年 → 死亡
```

**童年有童年的世界。** 孩子有自己的社交、规则、残忍、秘密。孩子会长成大人想不到的样子。

**老年不只是变慢。** 记忆在流失，性格在变，时间感在错乱，可能把孙子当成死去的儿子。

**死亡有过程。** 病死还是猝死，有没有告别，葬礼怎么办，谁来哭，谁来抬，遗物怎么分，他死后的第一顿饭有没有人给他留位置。

【已交付 v1.5.0】life.js：STAGES 五段（婴儿 0-2 / 儿童 3-12 / 少年 13-17 / 成年 18-59 / 老年 60+）；童年 decideChild（孩子不做工、不进矛盾、不装病，婴儿 nest 守在母亲身边）；老年 elderDaily 记忆真删除 + elderConfusedSay 认错人（把活人认成故人）；死亡有过程：dailyMortality（年纪越大风险越高）→ startDying 病榻 2-5 日（rest-sick）→ dieAndFuneral（坟茔上图、遗物、讣闻、享年镇记、葬礼启动）；funeralTick 送葬人到坟前哭丧（WAIL_LINES 气泡+记忆，只记一笔）。渲染：身量缩放 0.75/0.88/1 + headTop 统一锚点，坟茔 tile 与小地图色块；UI 镇魂碑列故人档案。

## 十一、遗传与传承 【已交付 v1.5.0】

外貌从父母零件库随机组合；性格是父母性格向量的加权平均 + 随机扰动；天赋小概率突变。AI 只生成一个独有特征。

**记忆传承**：父母的部分记忆以故事形式传给子女，传三代后失真，变成传说。

【已交付 v1.5.0】life.js：makeChildDef（姓随父、发色父母 44%/44% + 12% 五色突变、性格 25% 概率突变一项、traits 父母各取其一）；pairCheck 成年未婚 5%/日 好感门槛配对互设 spouse；tryBirth 有配偶 0.8%/日 生育，addBorn 婴儿随父入户/家谱双向挂载/父母记忆/图集重注册，18 岁 assignAdultJob 转职。记忆传承（故事化三代失真）待后续版本。

## 十二、人口流动 【部分·移民与离镇已交付 v1.6.0】

**推力**：资源不足、社交冲突、好奇心、野心。
**拉力**：繁荣度、声望、安全度、恰好路过。

移民、殖民、迁徙、贸易四种类型。

【已交付 v1.6.0】pullScore 推力（冲突/孤独/野心）+ pushScore 拉力（繁荣/声望）→ departReason 离镇 → finalizeDepart 入 left 镇史；makeTravelerDef + addTraveler 外来者迁入（有空房则继承，落脚期）。【部分】v1.1.0 scout 探索发现已交付；殖民、迁徙、贸易待 v1.7+ 物质层/世界层。

## 十三、独特性随时间累加 【设计已定】

两个 NPC，出生时档案 95% 相同。第 1 天遇到不同的人，第 10 天经历不同的事，第 100 天技能树分叉，第 1000 天是完全不同的人。

**分叉是指数级的。你不需要一开始就让他们很不同，只需要让他们每天多分一点点。**

# 第四章 AI 架构

## 一、三层思考 【部分】

```
L3 慢思考（LLM）  每游戏日 1-5 次 / NPC
L2 中思考（规则）  每游戏分钟
L1 快思考（状态机）每帧
```

**LLM 只负责 L3。** L1（NPC.tick）+ L2（scriptDecide 效用 AI）+ L3（LLM 批量决策）三层雏形都有，接口已通。

## 二、核心原则 【已交付·设计已定】

> **AI 生成数据，引擎解释数据。代码不动，世界在长。**

自由给在数据层，稳定守在引擎层，中间用校验器隔开。

## 三、数据契约 【已交付 v1.3.0】

每种数据有固定的结构，引擎只认契约里的东西。**契约之外一律拒收。**

契约要设计得宽：自由字段（AI 塞结构外的补充）、条件字段（什么情况下有效）、概率字段（不一定成功）。

**格式宽一分，世界能长的空间就大一分。**

**v1.3.0 实现**：`contract.js` —— 意图五要素（type/params/priority/reason/expiresAt/source）、校验器（未知类型/不可达/进他人家/单日超限→降级翻译）、概率字段、条件字段、自由字段。

## 四、接口 【部分】

**NPC 大脑接口**（同一抽象类，可热插拔）：`decide(上下文) → 意图列表`、`on_event(事件)`、`on_day_end()`。

三种实现：纯规则（永远可用）、LLM（异步带缓存）、混合（默认）。

**感知上下文**必须是可序列化的纯数据。

**意图**：类型、参数、优先级、**理由（必填）**、过期时间、来源。

**理由字段是整个项目的调试命脉。**

【部分】现状：有 snapshot 与 applyDecisions，理由字段已强制（缺理由自动补"（没说为什么）"）。

## 五、校验与仲裁 【已交付 v1.3.0】

LLM 输出 → JSON 解析 → 校验器 → 合法意图入队。

校验：目标可达、资源够、技能够、物理可行、不拆别人的家、单日意图上限。

**校验失败不报错崩溃，而是降级**——把非法意图翻译成最接近的合法意图。

**v1.3.0 实现**：`validateIntent` + `fallbackIntent` + `probPass`。

## 六、模型池 【部分】

设置里能加、能减、能分配。四种策略（自动/绑定/按任务/加权轮询），重要度分层（核心/普通/背景/一次性），故障链（主力→备用→本地→脚本→静默降级）。

**不同模型说话风格不同**：好处是自然差异化，坏处是世界观会散。**解法：注入统一的小镇语感。**

【部分】现状：有基础 API 配置（接口地址/密钥/模型/决策间隔/测试连通），无池、无分层、无故障链。

## 七、性能 【部分】

- 分层读取档案，秘密层**永不进 prompt**（只通过行为体现）
- 决策必须异步
- 夜间批量预生成第二天对话
- 相同情境的决策可以复用

## 八、铁律 【已交付·设计已定】

1. 没有 LLM 也必须能玩
2. AI 只能提议，系统负责裁决
3. 每个决策必须可解释
4. AI 生成零件和决策，不生成成品

# 第五章 营造与开拓

## 一、材料是真的 【已交付 v1.7.0】

```
活树 → 砍倒 → 原木 → 搬运 → 木匠加工 → 木板 → 运到工地 → 搭建
```

**每一环都要有人、有时间、有地点。运输本身是一件事，不是瞬间完成的。**

【已交付 v1.7.0】harvestObj 砍树→地上 `O.LOG` 实体原木（树1-2/桩1，res:'log' 不入抽象镇库）；haulJob 搬运四站（load→drop→pick→store）；millJob 樵夫锯木；仓库 `O.BARN` 实体容量封顶 `MAT.BARN_CAP=60`；工棚 `O.SHED` 缺料灰进度条等待、材料齐才推进；maintDaily 磨损/荒废/腐烂/失窃。

## 二、六个环节 【已交付 v1.7.0】

**采集**：砍树留桩，地上出现实体原木（`O.LOG`，可被搬走、雨淋 0.3/晴 0.04 每日腐烂判定）。
**搬运**：haulJob 闲人扛（缺料工地优先背板 2块/趟 > 拾原木 1根/趟 > 修缮），四站往返 load→drop→pick→store。
**加工**：樵夫 millJob 驻坊锯木，3 根原木出 2 块木板（`MAT.LOGS_PER_PLANK=3`/`PLANKS_PER_BATCH=2`），损耗归边角料。
**储存**：仓库 `O.BARN` 容量封顶 `MAT.BARN_CAP=60`，满拒产不吞料；每日失窃 0.03。
**施工**：缺料工地 `_waited` 不涨进度条（render 灰色），材料齐才推进；天气逻辑沿用 events.js。
**维护**：每日磨损（晴 6%/雨 12%）→ v≥3 塌 `O.RUIN`；空房 15%/日 wear+1 → v≥3 塌半边+门口 RUIN；repairTick 修缮恢复。

**废墟不是"建好又删掉"，是"没人修，慢慢垮"。** 【已交付 v1.7.0】`O.RUIN` 实体 + 修缮 + canPlaceSite 允许在废墟上重建。

# 第六章 发展 【已交付 v1.9.0】

## 一、约束只来自物理

不定技术上限，不设科技树，不划分时代。**一个 NPC 可以想到任何东西。能不能做出来，看世界给不给。**

| 约束   | 含义                |
| :--- | :---------------- |
| 材料   | 需要的原料在不在这个世界上     |
| 能量   | 有没有可用的动力源         |
| 人手   | 需要协作，而人口有限        |
| 时间   | 任何东西都要工时，而人有寿命    |
| 精度   | 想造复杂的，得先有造复杂东西的工具 |
| 知识载体 | 知识存在人脑里，会随人死而消失   |

**只要世界里有煤、有铁、有水、有人，NPC 自己就能走到蒸汽机。反过来，如果这个世界没有煤，蒸汽机就永远做不出来。不是禁止，是没有原料。**

## 二、瓶颈驱动

**人不会闲着没事改进工具。只有被逼到一定程度，才会想"这破东西不好用"。**

**反直觉但真实的结果：繁荣期停滞，危机期创新。**

## 三、配方可以被改写

NPC 反复用同一个配方遇到瓶颈，会尝试变体。成功就留下，失败就丢掉。**发展不是解锁，是变异加选择。**

## 四、想法在等条件

**不是"配方变异 → 选择 → 保留"，是"NPC 想到 → 世界答不答应"。**

**一个想法可能被想到过一百次，但只有第一百次的世界，才容得下它。**

## 五、知识会死

**知识不写在代码里，存在人脑里。** 会做某种东西的匠人死了，手艺可能失传。

**世界不只会发展，还会倒退。重新发明一件事，比第一次发明更难。**

## 六、传播比发明更重要

匠人自己会 → 徒弟学到 → 邻居看到 → 别家模仿 → 变成常识。每一环都可能断。**大部分发明都死在了发明者手里。**

## 七、地域差异

同样的起点，不同的环境，长出不同的技术路线。

## 八、怎么防止走向荒谬

三道天然闸门：材料上限、规模上限、知识衰减。

**结果：世界会发展，但不会失控。玩五百年，可能从斧头到水力锯到风车磨坊，但不会出现电。**

# 第七章 灾难与崩溃 【已交付 v1.9.0】

## 一、灾难不只来自技术

技术性（快）、生态性（慢但不可逆）、传染性（中速）、社会性（慢，看不见）、外源性（突发）。

**它们会互相放大。** 没有哪一个单独致命，是叠加起来的。

## 二、社会能不能应对

六环：有没有人看见 → 看见了有没有人信 → 信了有没有权力管 → 管了有没有人听 → 听了来不来得及 → 扛住了会不会内乱。

**这六环，断一环就崩。全部是涌现的，不是预设的。**

## 三、失败的方式

无人察觉 / 被当成疯子 / 没有权力 / 利益冲突 / 管得太狠 / 扛住了但变了。

## 四、崩溃之后

房子没人修 → 塌。田地没人种 → 荒。工具没人做 → 丢。知识没人传 → 断。

**然后，新的东西会从废墟里长出来。** 幸存者捡到旧时代的工具，看不懂，当成神器。传说"以前这里很繁荣，后来神发怒了"。

**玩家是唯一知道真相的人。你看着它灭亡，然后看着它被遗忘。**

## 五、世界会自己修复

修复成什么样，取决于它经历过什么。一片被火烧过的森林，恢复后可能变成草原。

**继续看，不重开。一个世界可以死很多次，也可以重生很多次。**

# 第十章 历史与痕迹 【已交付·第八遍呈现层 v2.0.0】

## 一、四种结果

| 结果   | 比例  | 玩家感受  |
| :--- | :-- | :---- |
| 事后能懂 | 30% | 延迟满足  |
| 部分可懂 | 40% | 拼图有缺口 |
| 永远不懂 | 30% | 神秘感   |

**决定能不能懂的不是设计者，是痕迹。** 痕迹留不留，由行为本身决定，不由系统决定。

## 二、五种痕迹

文字（几十年）、口述（传三代变形）、物理（几百年）、关系（一代人）、行为（只要他活着）。

**事后看懂的条件：至少两种痕迹能对上。完全不懂的条件：只有一种，或者没有。**

## 三、痕迹会衰减，方向不可控

衰减不是均匀的，取决于它被什么东西保护。

## 四、必须保证完全不懂的存在

独处时做的事、被销毁的证据、死者脑中的秘密、自己都忘了的事、时间抹掉的东西。

**这些不是待挖掘的内容，而是本来就不存在的内容。**

## 五、玩家的考古工具

编年史（系统写骨架，NPC 写血肉）、传闻网、地形考古、关系演变、高光回放（只能看你当时在看的视角）。

**玩家没有上帝视角的回放。错过的，就是错过了。**

## 六、让玩家知道这里有东西

三个信号：反常、空白、遗物。

## 七、保底的可理解性

日常行为必须能懂，关系变化必须能懂，重大事件必须能懂。

**不懂只应该出现在深层动机和秘密上，不应该出现在表层行为上。**

# 第十一章 演化系统 【已交付 v2.3.0】【演化之脑 v2.6.0】【白纸开局 v2.7.0】

【已交付 v2.3.0】evolve.js：内容层 7 种提案契约（配方/语言/习俗/事件模板/建筑组合/社会角色/说法），铁律层不动；六条永恒定理物理校验（守恒/因果/时间/空间/代价/有限），失败降级或丢弃不报错；5 种缺口信号扫描（未定义状态 gap / 重复临时方案 repeat / 玩家间接反馈 player / 周期审查 review / NPC 自己想到 npc——第五种每日扫，矛盾摆到极端的人心里长念头）；落地流程提案→校验→候选池(上限24)→灰度(1-2 人或一块 4×4 地皮试 7 天，同时最多 3 个)→观察(试行的人死光/心情烂透/物资亏空/废墟连片即回滚)→固化(全镇铺开)/修正(缩范围减力道,上限 2 次)/回滚(痕迹留镇史)；演化日志给玩家看（神谕面板演化 Tab：改了什么、为什么、之后如何，点一条展开灰度范围与观察记录）；风向开关（≤20 字，预设繁荣/战乱/和平/探索，留空自动）只作暗示注入提案 prompt——你说，他们自己理解；无 LLM 时脚本兜底保守提案，离线仍转动。演化新配方注册运行时 recipeDefs（铁律层 RECIPE_DEFS 不动），参与传承/失传/重发明。验证：selftest 阶段33 十二组断言全过（771 项），smoke230 CDP 冒烟 28 项全过。

## 一、AI 帮忙演化

**能碰的（内容层）**：配方、语言、习俗、事件模板、建筑组合、社会角色、说法。
**不能碰的（铁律层）**：六条永恒定理、引擎本身、校验器的裁决权、数据格式。

**核心原则：AI 生成数据，引擎解释数据。**

## 二、AI 怎么发现缺口

未定义状态、重复的临时方案、玩家的间接反馈、周期审查、**NPC 自己想到**。

**第五种最重要，也最符合"演化"。**

## 三、落地流程

```
AI 提案 → 物理校验 → 候选池 → 灰度生效 → 观察 → 固化/修正/回滚
```

**任何新东西不能一上来就全镇铺开。**

## 四、演化日志

AI 改了什么、为什么改、改了之后发生了什么，全部要记下来。**不只是给开发者看，是给玩家看。**

## 五、玩家可以暗示方向

默认自动，但保留一个风向开关。**你说，他们自己理解。**

## 六、模型池：两条 AI 的脑分开 【已交付 v2.6.0】

【已交付 v2.6.0】ai.js 三层模型池：**第一层 NPC 模型池**——聚合网关/多家直连端点（providers 每行`地址|密钥|模型1,模型2`），byPersonality 确定性分配（traits+pers+id 哈希取模，零随机可 seed 复现，缓存 n.aiModelId 随档走），决策按模型分组多模型并行调用——**不同模型对同一份性格快照给出不同的处世味道，声音自然分化**，一组挂了组内故障转移不拖垮全镇；**第二层演化独占**——演化引擎独占高能力免费模型（首选 gemini-2.5-flash，备援 glm-4.7-flash/qwen3-235b），链序主→备援→本地兜底，不与 NPC 池共享额度（演化低频调用不抢居民额度）；**第三层故障链**——池端点→池内转移→本地 Ollama→脚本本能，游戏永不因 API 问题卡死，降级全程记 aiChainLog（最近 20 条）。prompt 一字不改：分化的来源是模型本身，不是 prompt 编排。三段配置默认关闭=v2.5 行为，旧档无缝升级。develop.js 的 variants 倍率阶梯保留为离线脚本兜底层（脚本创新的通路），AI 提案链才是真演化。验证：selftest 阶段36 八组断言（952 项），smoke260 CDP 冒烟 25 项。

## 七、白纸开局：职业是长出来的，不是带来的 【已交付 v2.7.0】

# 第十三章 玩家 【设计已定】

## 一、你是什么

**你是环境的一部分。** 就像太阳、雨水、地震。太阳只是在那，万物自己决定怎么回应它。

你下雨，不是因为你想让谁丰收。你只是下雨了。至于农民是高兴还是骂娘，那是他们的事。

## 二、你能做什么（四件事）

| 操作       | 说明                       |
| :------- | :----------------------- |
| **改天候**  | 改的是概率，不是结果。不能指定下到谁头上     |
| **改地貌**  | 埋矿脉、改水源、动地形              |
| **丢事件**  | 流星、瘟疫、旅商、野兽，丢下去就不管了      |
| **给一段话** | 神谕/低语。只进 NPC 的记忆，不产生任何数值 |

就这四件。**没有额度，没有冷却，没有代价表。想改就改，改完看它自己发酵。**

【部分】现状：前三种已交付（天气/地貌画笔/事件卡），神谕（低语/昭告）已交付。

## 三、你不能做什么

- 不能直接命令 NPC
- 不能看 NPC 内心
- 不能指定干预结果
- 不能阻止世界自己演化
- 不能精准指定下雨下到谁头上

**你只能施加，不能指定。** 你永远处于"我做了件事，然后看它自己发酵"的状态。

【已交付·设计已定】

## 四、玩家自己也看不懂

玩家应该是这个世界里最慢的观察者。他的理解速度，就是游戏的情感节奏。

**如果玩家永远比 NPC 慢一步，那这个游戏永远有"事后看懂"的空间。**

【设计已定】

## 五、情感入口

这套机制要成立，需要玩家愿意花时间去考古。但绝大多数玩家不会主动挖。

**所以真正的问题不是怎么设计痕迹，是怎么让玩家在第一天就爱上一个人。**

如果他不爱任何人，他就不会想知道任何人的秘密。

【设计已定·待居民系统落地后处理】

## 六、信仰系统（已删除）

**信仰值整层删除，不留残余。**

删除清单：信仰值（数值/显示/消耗）、三种信仰质地（感恩/敬畏/仪式）、可借/透支/通胀、无神论者通缩、神的死、神的瞎、能见度、信仰决定视野范围、干预冷却。

**保留**：只留"改概率不改结果"和"连锁不可控"两条——不是系统，是手感。

**"神"这个词作为视角代称留着**，但"神与人"之间不再有任何系统。

【已删除·v2.1】

**名字怎么起、话题聊什么、喜歌唱什么、临终哭什么——这些不该有一字一句是程序写死的。** 上一轮的断链：过程革命让"怎么做"活了，但"说什么"仍散落在 8 个文件的话术常量池里——CHAT_TOPICS/STORY_LINES/WEDDING_SONGS/PET_NAMES/MOTTOS……世界说自己会演化，嘴里说的话却句句是开发者的台词。v3.1.0 把语言拆成两层，红线划法与过程革命同构：**词素怎么组合成句是物理**（LEX_SLOTS 36 话位名册——闲聊话题/孩子话题/吵架起手/和好台阶/过日子的话/口头禅/新生儿名/外来人姓氏/伴侣名/方言对/传话换词对/禁忌词/心结/常见心事……每槽带 cap 上限与六种形状 phrase/word/pair/group/ab/secret，这是允许硬编码的铁律层，就像语法机制也是物理）；**具体词库内容是演化设定**（game.lexicon 随档走，开局=SEED_LEXICON 种子词表——与 ROSTER 种子居民同级的初始条件不是机制；演化第 8 种提案 'lex' 进内容层，payload {slot, entry}，validateLex 形状校验+撞词丢弃，灰度试行者"琢磨出个新说法"，超帽 FIFO 退役、回滚拔除且被挤退役的旧词不复活——**旧词会死，语言才活，这也是时间不可逆**）。词库每天自己漂移：6% 变异一词（方言化换词/长句掉字）、4% 退役一词（词数过地板才允许死）；新生儿名字/心性、外来人姓氏、初生声音、心结措辞全部从当下词库抓——两个镇子开局同日，十年后说两种话。兜底文案零硬编码：scriptPropose 的习俗名/事件名/角色名全部从词库组装或变异旧词（词从词里长），词库真空由校验器自然丢弃（优雅降级）。scanReview 新缺口：chatTopic/motto/catch 词数跌破地板 → 报"该有人琢磨新说法"。铁律不破：无 LLM 也必须能玩——种子词表就是 bootstrap，演化只是让它继续长。selftest 41 阶段 1154 项全绿（阶段41 十一组：36槽名册+种子全覆盖/词库独立性/pickLex 全槽覆盖+空game落种子/新生儿外来人声音心结从当下词库抓/形状校验/lex 提案全周期/超帽FIFO退役/漂移确定性/兜底随词库变/存档往返逐词一致+老档落种子表/prompt 带第8种+话位名册）；smoke310 冒烟 23 项——页面内词库 36 槽运行时就位、聊天话题 20 次全在槽内、lex 提案撞词drop→pass→灰度入库→固化→回滚拔除全链路、30 天连跑零 JS 错误无空槽（退役地板保底）、存档带词库逐词一致、老档落种子表；smoke230/240/250/260/270/280/290/300 回归全绿；便携版实机 20 秒零 JS 错误、36 槽就位。设计稿：.trae/documents/语言革命设计.md。

# 第十六章 铁律

1. **框架稳定。** 六条定理永远不变，AI 碰不到。
2. **没有 LLM 也必须能玩。** 所有 AI 逻辑都有纯规则降级路径。
3. **AI 只能提议，系统负责裁决。** 校验器是唯一真理来源。
4. **每个决策必须可解释。** 理由字段为空等于代码不通过。
5. **AI 生成数据，引擎解释数据。** 代码不动，世界在长。
6. **世界可以死。** 没有保底，没有救世主。
7. **画面不达标不许往下做。**
8. **先做能玩的，再做聪明的。**
9. **存在本身要被看见。** 不能为了"看起来有事做"而压缩存在态——那背离"活着"。

# 尾

它是一个生态箱。

没有主角，没有目标，没有结局。只有一群有自己生活的人，在一个无限延伸的世界里，自己走自己的路。

你看着他们出生、长大、相爱、争吵、建造、离开、死去。你偶尔伸手拨一下天气，偶尔埋一条矿脉，偶尔给某个人托个梦。

你永远不知道下一秒会发生什么。但你事后永远能理解，或者永远不理解。

世界不会因为人死了而哀悼，也不会因为人活了而欢喜。

**但对他们不是零。这才是重点。**
