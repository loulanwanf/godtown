# 语言革命设计（v3.1.0）：词库是演化设定，语法才是物理

> 继过程革命（v3.0.0，动作原语）之后，把"人嘴里说的话"也拆成两层。
> 零内容红线：硬编码的台词池全部拆除，词库成为随档走、可增可减、会漂移的活数据。

## 一、两层拆分（同过程革命的同构关系）

| | 过程革命 v3.0.0 | 语言革命 v3.1.0 |
|---|---|---|
| 物理（允许硬编码） | MOTION_PRIMS 动作原语名册 | LEX_SLOTS 话位名册 + 语法机制（方言替换/口头禅装饰/{n} 填槽/漂移） |
| 内容（演化设定） | OBJ_MOTION / def.motion | game.lexicon（随档走） |
| 校验洗练 | validateRecipe motion | validateLex（checkLexEntry） |
| 离线兜底 | 落「揉压」通式 | scriptPropose 从当前词库组装/变异 |
| 漂移 | — | lexiconDaily：词会变异、会死 |

**话位（slot）是物理**：人会问候、会否认、会质问、会哭丧、会取名、会带口头禅——这是人性，与"人有手会挥会压"同级。
**话位里的词条是内容**：具体说"今儿日头好"还是"昨晚雨真大"，是这个镇子的语言，不是引擎的语言。

## 二、话位名册 LEX_SLOTS（lexicon.js）

- phrase（整句）：chatTopic/childTopic/childIdle/quarrelA/quarrelB/reconcile/mediate/deny/slyHint/tabooRetort/lament/confused/nursery/story/weddingSong/shared/unsaid/misread/motto/persChild/persOut
- word（单词）：catch/customTheme/eventTheme/roleName/dutyWord/nameGiven/outSur/outGiven/petDog/petCat
- pair（对子）：dialect（标准→方言）/swap（传闻变形近义对）
- group（词组）：taboo
- ab（心结对）：conflict {key,a,b}——**矛盾的种类是物理**（CONFLICT_KEYS 六种：leave/please/guilt/novelty/confess/duty，机制挂钩 pushScore 的 leave）；**措辞是内容**
- secret（心事）：secretGen {content, kw[]}——kw 是 probeSecret 的匹配钩，自由词即可

每槽有 cap（有限定理）：超 cap 先进先出——**旧词会死，语言才活**。

## 三、词库生命周期

1. **开局**：`initLexicon()` 拷贝 SEED_LEXICON——种子词表是初始条件（同 ROSTER 种子居民的地位），不是机制。
2. **取用**：`pickLex(game, slot, rng)`；game 为空时落种子表（selftest/纯函数兼容）。
3. **增词**：演化提案新种类 `lex`（第 8 种内容）——slot 必须在名册、形状校验、去重；灰度试行者"琢磨出个新说法"，固化入词库，回滚拔除。
4. **漂移**：`lexiconDaily` 每日小概率——变异（方言化换词/长句掉字，复刻传闻变形机制）或退役（词数过半槽才允许死）。
5. **随档走**：`game.lexicon` 顶层序列化；旧档缺省落种子表。
6. **新生儿说新话**：`makeVoice(def, lex)`——孩子出生从**当下词库**抓口头禅/方言/禁忌，三代之后祖辈的话孙辈听着费劲（第八章）。
7. **童谣修补**：原 `def.job==='学生'` 判定在白纸开局后永远为空——改按年龄（≤17），这是机制 bug 修复。

## 五、不动的（物理，写明理由）

- TRAIT_POOL/OUT_TRAITS/PET_PERS：性格词挂机制钩（倔→不买账、暴躁→恐惧、精明→撒谎），是封闭名册=物理。
- CONFLICT_KEYS：六种撕扯的种类=物理；措辞=内容（槽 conflict）。
- RELIC_BY_JOB/SECRET_TEMPLATES/WORK_HOURS 等职业残留：归 ③。
- AREA_DEFS：归 ④。ROSTER：种子居民=初始条件（与种子词表同级）。
- STOCK_NAME/G_NAME/O_NAME/WEATHERS：物理物件的 UI 名词。
- 语法机制：方言替换、口头禅装饰、{n} 填槽、换词变形、掉字变形。

## 六、演化接口

- PROPOSAL_KINDS 7→8，加 `'lex'`：payload `{slot, entry}`。
- validateLex：槽在名册 → checkLexEntry 按形状洗练（phrase≤20 字/word≤6 字/pair 各≤6/group≤3 词/ab 须 key 合法/secret 须 content+kw≤3）→ 去重。
- applyProposal('lex')：入词 + 超 cap FIFO 退役（演化日志记"旧词没人说了"）。
- rollbackProposal('lex')：拔除该词（说出口的话收不回，但没传开的词可以没人再说）。
- scanReview 新缺口：话位瘦到半槽以下 → "镇上的话越来越少了"。
- ai.js buildEvoPrompt：内容层 8 种 + 话位名册与形状说明。
- 离线：scriptPropose('lex') = 该槽现有词条变异一个（词从词里长）。
