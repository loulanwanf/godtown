# 过程革命设计（v3.0.0）

## 破题

产出革命（v2.9.0）让"做什么"活了——配方由演化长出、产出守恒对账。但"怎么做"仍是装的：NPC 站在原地，库存数字一跳，活就"干完了"。用户原话：**"不能做什么就是在原地站一会就有了，得有实打实的动画过程，这些也不能硬编码也得让演化引擎来设定。"**

这句话有两个要求，必须拆开：

1. **实打实**——渲染层要画出动作过程，帧与帧必须不同（原地站着帧差为 0）
2. **不硬编码**——"什么活用什么动作"不能写死在代码里，要由演化引擎掌管

## 两层拆分（红线）

| 层 | 内容 | 允许硬编码？ |
| --- | --- | --- |
| 铁律层（物理） | 动作原语**怎么画**：七个原语的相位函数/粒子/工具形状 | 允许——和重力、天气怎么画同级 |
| 内容层（设定） | **什么活用什么动作**：采集挂世界对象、加工挂配方 motion | 禁止——演化引擎通过提案契约设定 |

类比：重力怎么作用（物理）vs 这个世界有没有铁匠（内容）。动作原语的"画法"是物理，"分配"是内容。

## 原语名册（core.js 单一事实源）

```js
MOTION_PRIMS = {
  swing: 挥劈（砍割）  rate 1.1  fx chip   默认工具 axe
  smash: 抡砸（矿锻）  rate 0.85 fx stone  默认工具 pick
  pull:  拉拽（钓）    rate 0.5  fx splash 默认工具 rod
  stir:  搅舂（拌捣）  rate 1.3  fx dust   默认工具 stick
  knead: 揉压（通式）  rate 1.0  fx dust   默认工具 hand
  tend:  俯身照料      rate 0.75 fx drop   默认工具 hand
  saw:   拉锯（锯木）  rate 1.0  fx chip   默认工具 saw
}
MOTION_TOOLS = hand/axe/pick/rod/hammer/saw/stick   // 渲染层认识的工具形状（物理）
```

knead 是通式兜底：任何没设定/乱编的动作都落到揉压并留痕，世界永不停摆。

## 动作从哪来（三条通路）

1. **采集：OBJ_MOTION**（世界对象的物理属性）——ROCK/COPPER/IRON/GOLD→smash+pick；TREE/STUMP→swing+axe；BUSH/CROP0-2→tend；CROP3→swing+hand；CHEST→smash+hand。对象决定动作，和"对象决定产出"（GATHER_OBJS）同一哲学。
2. **加工：def.motion**（演化引擎设定）——提案 recipe 的 payload 必填 `motion:{prim}`，validateRecipe 洗练（缺带/非法 prim→knead+留痕 fallback；工具非法→prim 默认工具），applyProposal 落表带 motion，serializeEvo 整 def 存储自动随档。演化之灵在 buildEvoPrompt 里看得到整本原语名册+挑选指引（"按手艺的性质挑最像的那个"）。
3. **工种：tick 分支直挂**——build/repair→smash+hammer，mill→saw，钓鱼→pull+rod（朝水面）。

解析降级链：`motionFor(prim,tool)` 非法 prim 返 null / 非法工具落默认；`motionForObj(ov)` 对象无映射返 null；`motionOf(def)` 老档/非法配方落 knead 通式。任何一环断了都有下一环接住。

## 渲染（render.js）

- `npc.act` 瞬态状态（**不存档**，读档由 intent+数据重建）——动作是"正在发生"的事
- 相位 `ph=(time×rate+idOff)%1`，idOff 按 NPC id 错拍，全镇不齐步
- 每原语相位函数：swing 0.45 蓄力→0.62 劈下；smash 0.52/0.68 大弧；pull 0.55-0.75 猛提；stir 圆周；knead sin 推压；tend 双窗俯身；saw 往返
- 手臂=上衣色两节像素臂，肩点→手部关节→工具逐像素线段（axe/pick 木柄+铁头）
- 命中窗口蹦粒子：chip#d9b078/stone#aab0b8/splash#8fc3e8/drop#7fb8dd/dust#c9bfa8，hash2(cyc,seed) 确定性抖动 2 粒子
- 干活朝着活计：faceTo 按对象方位设 dir

## "实打实"的判定

落地成像素级断言（smoke300）：离屏 canvas 同一 NPC 同一动作不同时刻渲两帧，**帧差>30 判定动画真的在变**（实测 148/64；原地站着帧差为 0）；七原语逐个画全部非空。

## 交付边界

原语名册七个是当前物理的全部。演化引擎想长出新原语（如"编织"）不在本轮——那是"物理定律扩展"，需显式提案+校验器升级，不是内容提案能碰的。
